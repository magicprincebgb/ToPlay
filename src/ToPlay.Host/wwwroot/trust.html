Make ToPlay secure on this phone

ToPlay streams your PC over your own Wi-Fi using its own certificate. Installing that certificate once removes the “Not secure” warning and lets ToPlay install to your home screen with the proper icon. It takes about a minute.

1 Download the certificate

Must be downloaded over plain http — that’s why this page isn’t https.

Download ToPlay certificate

2 Install the profile

  1. Tap Allow when Safari asks to download a configuration profile.
  2. Open Settings → Profile Downloaded (near the top) → Install.
  3. Enter your passcode, then tap Install again.

3 Turn full trust ON (required)

iOS installs the certificate but does not trust it until you flip one switch:

  1. Settings → General → About
  2. Scroll to the bottom → Certificate Trust Settings
  3. Turn ToPlay Local CA ON and confirm.

Skipping this step is the #1 reason the warning comes back.

2 Install it as a CA certificate

  1. Open Settings → search for certificate.
  2. Choose Install a certificate → CA certificate → Install anyway.
  3. Pick the downloaded ToPlay-CA.crt from Downloads.

Some phones name it “Encryption & credentials” or “Install from storage”.

4 Open ToPlay securely

Come back over https, sign in, then use Add to Home Screen for full-screen play.
